# 🌐 Personal Portfolio

A clean, modern, and performance-focused personal portfolio showcasing my work, skills, and personality — built with **vanilla HTML, CSS, and JavaScript**.

Live site: **[https://geanpaulo.com]**

---

## ✨ Features

- 🎨 **Minimal, modern UI** with light & dark theme support  
- 🌓 **Theme-aware components** (including favicon & UI elements)
- 🧠 **Dynamic content** powered by JavaScript (projects, quotes, greetings)
- 📝 **Rotating footer footnotes** for a personal touch
- 🖱️ **Custom cursor interactions**
- 📱 **Fully responsive** across desktop, tablet, and mobile
- ♿ **Accessible** with reduced-motion support

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (custom properties, animations, responsive layout)
- **JavaScript (Vanilla)**
- **Devicon** for skill icons
- **Cloudflare Worker** (for quote-of-the-day proxy)
- **GitHub Pages / Static Hosting**

---

## 🧪 Skills Highlight

The skills section uses a **CSS-only marquee animation**:
- Infinite horizontal scroll on desktop
- Static, wrapped layout on mobile
- Pauses on hover
- Respects `prefers-reduced-motion`

Icons are preserved for visual recognition and accessibility.
